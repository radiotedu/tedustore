# TEDU Store

Official store project of TED University.

## Overview

**TEDU Store** is a central repository for the TED University store / merchandise experience. It hosts the storefront source code, product catalog data, assets, and related documentation.

## Features

- Product catalog and collections
- Merchandise and apparel showcase
- Order / inquiry flow
- Responsive storefront UI
- Maintainable product data structure

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/radiotedu/tedustore.git
   cd tedustore
   ```

2. Open the project and follow the setup instructions in the relevant app directory (to be added).

## Project Structure

```text
tedustore/
├── README.md
├── docs/       # documentation (roadmap, guides)
├── assets/     # images, logos, design files
├── data/       # product catalog data
└── app/        # storefront application source
```
